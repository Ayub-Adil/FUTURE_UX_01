# FUTURE_UX_01 – Saloon Luxe Website Redesign

## 📌 Project Overview
This project was completed as part of my UI/UX Design Internship at Future Intern.

The goal of this task was to redesign a local service business website with a strong focus on:
- Lead Generation
- Conversion Optimization
- User Experience
- Responsive UI Design

The project was designed for a luxury grooming & beauty brand named **Saloon Luxe**.

---

## 🎯 Objectives
- Create a modern and visually appealing website UI
- Improve customer engagement and conversions
- Design clear service navigation
- Add lead generation and trust-building elements
- Ensure mobile-friendly user experience
